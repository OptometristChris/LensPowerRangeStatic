## 💡 프로젝트 소개

안경사로 근무하면서 렌즈를 주문할 때마다 브랜드별 여벌범위표를 확인했습니다. 같은 도수라도 브랜드, 굴절률, 설계, 코팅과 색상에 따라 여벌 가능 여부가 달라 여러 조건을 함께 살펴봐야 했습니다.

이 반복 작업을 줄이기 위해 **제품 조건과 S·C 도수를 입력하면 등록된 여벌범위에 포함되는지 확인하는 웹 프로그램**을 만들었습니다.

독학한 웹 개발 지식과 GPT를 보조 도구로 활용해 제작했고, 실제 주문 기준과 결과를 반복 대조하며 범위 데이터를 수정했습니다. 
GitHub에 공개한 뒤에는 동료들의 업무에도 실제로 활용되었고, 긍정적인 사용자 경험을 이뤄내는 데 성공했습니다.

## ✨ 주요 기능

| 기능 | 내용 |
| --- | --- |
| 5개 브랜드 선택 | 케미·니콘·자이스·토카이·다가스 |
| 제품 조건 선택 | 회사·굴절률·설계·코팅/색상 선택 |
| 선택 항목 연동 | 회사에 따른 굴절률·설계 목록과 제품 조건별 코팅/색상 목록 구성 |
| 도수범위 판정 | S값의 전체 범위와 S구간별 C값 조건을 순서대로 비교 |
| 판정 이유 표시 | S범위 초과, C범위 초과, 조건 데이터 없음 등을 구분하여 안내 |
| 브라우저에서 실행 | 별도 서버나 데이터베이스 없이 JavaScript로 처리 |

> 이 프로그램은 등록된 **여벌 도수범위**를 확인합니다. 제조사나 매장의 실시간 재고 수량을 조회하는 기능은 없습니다.

## 🖱 사용 방법

1. [프로그램](https://optometristchris.github.io/LensPowerRangeStatic/)에 접속합니다.
2. **회사 → 굴절률 → 설계 → 코팅/색상**을 선택합니다. 예: 케미 - 1.60 - 비구면 - 퍼펙트
3. **S값과 C값**을 부호와 함께 입력합니다. 예: `-4.25`, `-2.50`
4. **확인** 버튼을 누르고 가능 여부와 판정 이유를 확인합니다.

| 입력 항목 | 의미 |
| --- | --- |
| S값 | 구면도수 |
| C값 | 원주도수 |

현재는 특정 제품 조건을 직접 선택한 뒤 가능 여부를 확인하는 방식입니다.

## ⚙️ 동작 방식

범위표의 조건을 **회사 → 설계 → 굴절률 → 코팅/색상** 순서로 정리했습니다. 화면 선택지와 판정 데이터를 구분해 관리합니다.

| 데이터 | 역할 |
| --- | --- |
| `companyToProducts` | 회사별 설계 목록 |
| `refractiveIndexOptions` | 회사별 굴절률 목록 |
| `productMapping` | 화면의 한글 설계명을 데이터 조회용 키로 변환 |
| `extraOptionData` | 제품 조건별 코팅·색상 목록 |
| `rangeData` | 제품별 S범위와 C값 판정 조건 |

### S값에 따라 달라지는 C값 조건

S와 C의 최솟값·최댓값만 각각 비교하면 실제 범위표를 충분히 표현하기 어렵습니다. 그래서 전체 S범위인 `sRange`와 S구간별 C범위인 `cRules`를 나누었습니다.

확인 버튼을 누르면 다음 순서로 판정합니다.

1. 선택한 제품 조건의 데이터를 찾습니다.
2. 입력한 S값이 전체 허용 범위에 들어가는지 확인합니다.
3. S값에 해당하는 구간별 조건을 찾습니다.
4. 입력한 C값을 해당 구간의 허용 범위와 비교합니다.
5. 결과와 이유를 화면에 표시합니다.

예를 들어 등록된 **케미 / 비구면 / 1.60 / 퍼펙트** 데이터에는 다음과 같은 구간이 있습니다.

| S값 구간 | 허용 C값 범위 |
| --- | --- |
| -8.00 ~ 0.00 | -3.00 ~ 0.00 |
| -10.00 ~ -8.25 | -2.00 ~ 0.00 |

이처럼 S값에 따라 C값의 허용 범위를 다르게 적용합니다. 위 표는 현재 코드의 판정 구조를 설명하기 위한 데이터 예시입니다.

## 🛠 기술 구성

| 구분 | 사용 기술과 방식 |
| --- | --- |
| 화면 | HTML · CSS |
| 로직 | JavaScript · DOM 이벤트 |
| 데이터 | JavaScript 객체와 배열 |
| 배포 | GitHub Pages · GitHub Actions |

프레임워크와 별도 백엔드 없이 구성했습니다. 입력과 범위 비교는 브라우저 안에서 처리하며, 제품 조건을 갱신할 때는 `script.js`의 데이터를 수정합니다.

### 주요 파일

| 파일 | 역할 |
| --- | --- |
| [index.html](index.html) | 제품 조건·도수 입력 폼과 결과 영역 |
| [styles.css](styles.css) | 화면 배치와 스타일 |
| [script.js](script.js) | 제품 데이터, 선택 항목 갱신, 범위 판정 |
| 여벌범위표(니콘,자이스,케미,토카이,다가스).pdf | 저장소에 함께 보관한 범위표 자료 |
| [.github/workflows/static.yml](.github/workflows/static.yml) | main 브랜치 푸시 및 수동 실행에 따른 Pages 배포 |

### 로컬에서 실행하기

```bash
git clone https://github.com/OptometristChris/LensPowerRangeStatic.git
cd LensPowerRangeStatic
```

내려받은 `index.html`을 브라우저에서 열면 됩니다. 별도 패키지 설치나 서버 실행은 필요하지 않습니다.

## 📌 데이터와 사용 범위

- 판정은 `script.js`에 등록한 범위 데이터를 기준으로 합니다.
- 제조사의 최신 제품 정보나 공급 조건을 자동으로 동기화하지 않습니다.
- 프로그램 내 데이터는 2025년 초를 기준으로 하기 때문에 현재 해당 브랜드의 제품 도수 범위와 다를 수 있습니다. 
- 실제 주문 시에는 최신 제조사 기준과 공급 가능 여부를 함께 확인해 주세요.
